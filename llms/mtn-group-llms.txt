# MTN Group

> MTN Group is Africa's largest mobile network operator, headquartered in Johannesburg, serving roughly 290 million subscribers across around 16 African markets. It runs two public developer surfaces: the MTN Developer Platform (MADAPI) at developers.mtn.com, which publishes 200+ API products across 15 African markets and lets anyone download the OpenAPI/Swagger definition for a product without an account, and momodeveloper.mtn.com, an Azure API Management portal with a self-serve sandbox for the MoMo Collection, Disbursement and Remittance APIs. The catalogue is heavily TM Forum Open API shaped.

Authentication: OAuth 2.0 client_credentials against https://api.mtn.com/v1/oauth/access_token (token_type BearerToken, expires_in 3599) plus an x-api-key header. MoMo uses an Ocp-Apim-Subscription-Key per product together with a provisioned API user/key and the X-Target-Environment header. Versioning is URI-path (https://api.mtn.com/v1/...) and only the current and n-1 versions are supported. Dates are RFC 3339, MSISDNs E.123, countries ISO 3166, currencies ISO 4217. MoMo requests carry a unique X-Reference-Id (UUID v4) that acts as the idempotency and correlation key; replaying one returns 409 RESOURCE_ALREADY_EXIST.
